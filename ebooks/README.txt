Put your eBook PDF files in this folder.

Name each file after the product's id in lib/products.ts, for example:
  healing-the-broken-heart.pdf
  answers-for-the-questioning-heart.pdf

This folder is private: files here can only be downloaded after a verified
Paystack payment for that eBook (see app/api/ebooks/download/route.ts).
Do NOT put eBooks in the /public folder - anything there is free for anyone.
